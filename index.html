类型转换 最常见 bug

# 常见转换

list("abc")         # ['a', 'b', 'c']
tuple([1, 2, 3])    # (1, 2, 3)

# 陷阱1：int() 不能直接转小数字符串

int(float("3.14"))  # 3  ← 正确做法

# 陷阱2：input() 永远返回字符串

print(n + 1)        # TypeError! str + int
n = int(input())    # ← 正确，先转再用
print(n + 1)        # 43

# 陷阱3：字符串比较与整数比较
a = input()         # 输入 "9"
b = input()         # 输入 "10"
print(a > b)        # True! 字符串比较：'9' > '1'
print(int(a) > int(b))  # False ← 正确
input() 的本质
input() 返回的永远是 字符串
哪怕用户输入的是数字

要做计算 → int(input())
要做浮点 → float(input())
type() 检查类型
x = "42"
print(type(x))      # 
x = int(x)
print(type(x))      #
改错题常考：看到 input() 后直接用于计算，大概率缺少 int() 或 float() 转换

报错 / Part 1

六种常见报错 — 上半部分

IndexError: list index out of range
原因：下标超出列表范围
lst=[1,2,3]; print(lst[3]) ← lst只有下标0,1,2
修复：用 range(len(lst)) 或检查下标大小
TypeError: 'int' object is not subscriptable
原因：对整数用了下标 [] 或调用了不该调用的操作
x = 5; print(x[0]) ← 整数不能用索引
修复：检查变量类型，是否少了 int() 转换
TypeError: can only concatenate str (not "int") to str
原因：字符串和整数直接相加
n = input(); print(n + 1) ← n是字符串
修复：int(input()) 先转换类型
NameError: name 'x' is not defined
原因：使用了未定义的变量名
print(Score) ← 大小写写错，或变量未赋值
修复：检查变量名拼写，注意大小写
ValueError: invalid literal for int()
原因：把不能转换的字符串传给 int()
int("3.14") 或 int("abc")
修复：先用 float() 转，再 int()；或用 try/except
KeyError: 'name'
原因：访问字典中不存在的 key
d={"age":18}; print(d["name"])
修复：用 d.get("name")，找不到返回 None

  1. 安装 Node.js
    去 nodejs.org 下载安装
  2. 安装 DeepSeek-TUI 
    npm install -g deepseek-tui
  3. 注册获取 DeepSeek API Key
    platform.deepseek.com → API Keys → Create
  4. 配置 API Key 
    # Mac / Linux
export DEEPSEEK_API_KEY=sk-xxxxxxxx
# Windows PowerShell
$env:DEEPSEEK_API_KEY="sk-xxxxxxxx"
  5. 在项目目录启动 
    cd ~/homework
deepseek-tui

DeepSeek-TUI / 模式

三种运行模式

Plan 模式
只读分析，不修改文件
Plan Mode
> 分析main.py结构 发现3个潜在问题： 1. 第5行可能越界 2. 缺少类型转换 3. 缺少异常处理 [仅分析，未修改]
想先了解问题在哪，不让AI乱改时用
Agent 模式
每步操作都需要确认
Agent Mode
准备修改 main.py 第5行：lst[3]→lst[-1] 确认？[Y]es [N]o > Y 已修改 继续第12行... 确认？[Y/N]
初学者推荐：保持对每次改动的控制
YOLO 模式
全自动执行，不问你
YOLO Mode
> 修复所有bug 修复第5行...完成 修复第12行...完成 添加异常处理...完成 运行测试...通过 共修改 6 处
熟悉后使用，新手慎用

考试速查 + 工具汇总

数据结构
  • set()空集合 / {}空字典
  • 集合无序无重复不能索引
  • 不可变类型才能做dict key
  • sort()改原 / sorted()返新
输入 / 输出 / 运算
  • input()永远返回字符串
  • 用 int(input()) 转整数
  • %.2f 保留2位小数
  • x**(1/2) 开方
改错题重点
  • = 赋值 vs == 比较
  • IndexError → 下标越界
  • TypeError → 类型不匹配
  • int()不能直接转"3.14"
