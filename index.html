数据类型 / 可变性

可变 vs 不可变

不可变类型 — 创建后无法修改
  • int   整数       x = 10
  • float   浮点数    x = 3.14
  • str   字符串     s = "hello"
  • tuple   元组      t = (1,2)
不可变类型 可以 作为字典的 key
可变类型 — 创建后可以修改
  • list   列表      [1, 2, 3]
  • dict   字典      {"a": 1}
  • set    集合      {1, 2, 3}
可变类型 不能 作为字典的 key
类型可变有序可重复下标索引作 dict key
list是是是是否
tuple否是是是是
dict是无序key 唯一key 访问—
set是无序否否—
str否是是是是
单选：Python 序列类型不包括？ — 字符串、元组、列表都是序列，字典不是序列类型
单选：不是 Python 数据类型名的是？ — list/str/tuple/dict 都是，实数不是 Python 类型名

循环 / ASCII

ASCII — ord() 与 chr()

# ord() — 字符转数字
ord('a')   # 97
ord('A')   # 65

# chr() — 数字转字符
chr(97)    # 'a'
chr(65)    # 'A'

# 大题：循环输出 ASCII 对应字符
while True:
    s = input()
    if s in "nN":       # 输入 N 或 n 退出
        break
    n = int(s)
    if 0 <= n <= 127:
        print(chr(n))
    else:
        print("请重新输入")

考试重点 + 工具速查

数据类型
  • set() 空集合，{} 空字典
  • 集合：无序、去重、不能索引
  • 不可变类型才能做 dict 的 key
  • 字典元素无序，不支持下标
列表进阶
  • sort() 改原列表 / sorted() 返新列表
  • s[i:j:k] — stop 不含，k 是步长
  • [i for i in range() if ...] 推导式
  • s[::2] 取偶数下标；s[::-1] 倒序
程序设计
  • input() 括号内绝对不加提示文字
  • 有小数输出：%.2f
  • 用到三角函数：from math import sin,cos
  • x**(1/2) 开方，x**(1/3) 立方根
AI 工具
  • DeepSeek-TUI：npm install -g deepseek-tui
  • 三种模式：Plan / Agent / YOLO
  • opencode：curl 一键安装，多模型
  • 都需要 DEEPSEEK_API_KEY
